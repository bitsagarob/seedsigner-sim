SeedSigner wallet simulator

i

This is the real SeedSigner firmware, running in this tab. Its Python is executed by Pyodide (CPython compiled to WebAssembly) inside a Web Worker. The wallet code itself is unmodified; only the four places it reaches for hardware are replaced.

  • Display — the driver hands raw RGB frames to the page, which paints them into the canvas above.
  • Buttons — the worker blocks on the wallet's main loop and can never answer a message, so keys cross on a SharedArrayBuffer and wake it with Atomics.
  • Camera — your webcam via getUserMedia. SeedSigner reads QR codes with pyzbar, a C library with no WebAssembly build, so decoding is done by the browser's BarcodeDetector or by jsQR and the bytes are handed to the unmodified decoder.
  • Smartcard — simulated SeedKeeper and Satochip cards that answer real APDUs, because browsers have no smartcard API at all.

Nothing leaves your browser. The page declares a content security policy that permits no connections to any other origin, and there is no server to send anything to.

It is a simulator. Treat every key it shows as public and never type a seed phrase you rely on.

Source, and a build script that rebuilds this wallet from a pinned upstream commit so you can check the claim above yourself: seedsigner-sim. The device firmware lives in seedsigner-os.
